# 04 — Nhóm Xã hội · Tin học · Công nghệ

## 1. Địa lí — vẫn **3 phần** (giống KHTN về số câu)

TN: 50' · **18 MCQ + 4 Đ/S + 6 short**.

### Dạng câu hỏi điển hình

| Dạng | Format | Đặc thù |
|------|--------|---------|
| Nhận biết khái niệm, vị trí, số liệu | MCQ | |
| Đọc **Atlat / bản đồ / biểu đồ** | MCQ, Đ/S | Media bản đồ; CBT cần zoom ảnh |
| Phân tích bảng số liệu kinh tế – xã hội | Đ/S nhiều ý | Stimulus bảng |
| Tính mật độ, tỷ lệ, tốc độ tăng… | **Short** | Số |
| Khai thác kênh chữ + kênh hình | MCQ VD | |

**Ghi chú product:** Địa gần KHTN về scoring; khác ở **Atlat** (thi giấy được mang Atlat theo quy định từng năm — CBT thi thử phải quyết định: nhúng bản đồ vào đề hay mô phỏng trang Atlat). Đây là bài toán nghiệp vụ riêng, không giống Toán.

## 2. Lịch sử — **2 phần** (không trả lời ngắn)

TN: 50' · **24 MCQ + 4 Đ/S** · không Phần III.

### Vì sao không short?

Nội dung sử thiên về nhận biết–thông hiểu–phân tích tư liệu; ít “tính ra một số duy nhất” như Lý/Hóa. Phân hóa chủ yếu bằng **Đ/S trên tư liệu**.

### Dạng câu hỏi điển hình

| Dạng | Format | Đặc thù |
|------|--------|---------|
| Sự kiện – nhân vật – mốc thời gian | MCQ | |
| Nguyên nhân – kết quả – ý nghĩa | MCQ TH/VD | |
| Đọc đoạn tư liệu / tranh ảnh lịch sử | Đ/S hoặc MCQ | **Stimulus** quan trọng |
| So sánh hai giai đoạn / hai quan điểm | Đ/S 4 ý | |
| Khai thác lược đồ, bản đồ lịch sử | MCQ | Hình |

**Bank:** tag theo giai đoạn / chủ đề (VN, thế giới, chuyên đề); mức NB–VD. Ít cần engine short-answer.

## 3. Giáo dục kinh tế và pháp luật (GDKTPL)

Cùng khung **Lịch sử**: 24 MCQ + 4 Đ/S · 50'.

### Dạng câu hỏi điển hình

| Dạng | Format |
|------|--------|
| Khái niệm kinh tế / quyền–nghĩa vụ / điều luật mức phổ thông | MCQ |
| Tình huống pháp lý ngắn (ai đúng, xử lý thế nào) | MCQ / Đ/S |
| Phân tích biểu đồ số liệu KT–XH | Đ/S + stimulus |
| Nhiều phát biểu về cùng tình huống | Đ/S |

Gần **case study** — stem dài, cần UI đọc thoải mái (và có thể split pane).

## 4. Tin học — 2 phần **đặc biệt**

TN: 50' · **24 MCQ + 6 câu Đ/S** (không Phần III).

Phần II (6 câu Đ/S) theo phụ lục Bộ:

- **2 câu** cho mọi thí sinh  
- **2 câu** định hướng **Khoa học máy tính**  
- **2 câu** định hướng **Tin học ứng dụng**

→ Thí sinh làm theo chương trình/định hướng đã học; không phải ai cũng làm cả 6.

### Dạng câu hỏi điển hình

| Dạng | Format | Đặc thù |
|------|--------|---------|
| Khái niệm mạng, hệ điều hành, an toàn thông tin | MCQ | |
| Đọc đoạn **pseudocode / thuật toán** | MCQ / Đ/S | Monospace, indent |
| Phân tích quy trình / sơ đồ khối | Đ/S | Hình |
| Bảng tính, CSDL mức phổ thông (nhánh ứng dụng) | MCQ / Đ/S | Screenshot |
| Tư duy máy tính, độ phức tạp nhẹ (nhánh KHMT) | MCQ / Đ/S | |

**Hệ quả product:**  
1. Blueprint phải hỗ trợ **nhánh đề (track)** — `common | CS | applied`.  
2. Attempt của học sinh gắn `informatics_track` để chỉ hiện đúng bộ câu Đ/S.  
3. Render code block là must-have nếu mở môn Tin.

## 5. Công nghệ (Công nghiệp / Nông nghiệp)

Khung giống Sử/GDKTPL: **24 MCQ + 4 Đ/S** · 50'. Hai môn tách bank & topic (CNCN ≠ CNNN).

### Dạng câu hỏi

- Nhận biết vật liệu, quy trình, thiết bị, an toàn lao động / kỹ thuật nông nghiệp  
- Đọc bản vẽ kỹ thuật / sơ đồ quy trình (stimulus hình)  
- Tình huống vận hành – bảo dưỡng – môi trường (Đ/S)

Ít tính số kiểu short; nặng **hình kỹ thuật**.
